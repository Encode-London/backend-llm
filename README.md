# My CLI Application

## Overview
This project is a command-line interface (CLI) application designed to provide users with a simple and efficient way to interact with the system through various commands.

## Features
- Define and handle CLI commands
- Utility functions for input parsing and output formatting
- Unit tests to ensure functionality and reliability

## Installation


Create virtual environment


```
python -m venv backend-llm-env 
```



Install the virtual environment



Mac:
```
source backend-llm-env/bin/activate
```

Windows:
```
\backend-llm-env\bin\activate
```

To install the required dependencies, run the following command:

```
pip install -r requirements.txt
```

## Usage
To run the CLI application, execute the following command:

Give prompt in `prompt.txt`

```
python src/llm.py
```
